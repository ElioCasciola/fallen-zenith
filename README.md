Fallen Zenith is a fantasy RPG being built from the ground up in C#. Its console version lays the foundation for turn-based combat, character progression, and dungeon exploration.

Each run is a journey toward the final boss. Grow stronger, face tougher enemies, and make every decision count—death means starting again.

> Currently a clean .NET 10 console starter. Gameplay is not implemented yet.

## Run

Requires the **.NET 10 SDK**.

```bash
git clone https://github.com/ElioCasciola/fallen-zenith.git
cd fallen-zenith
dotnet run
```
